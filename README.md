This program was designed with using two Adafruit MatrixPortal S3 devices paired with two 128x64 RGB LED Matrix Panels (2mm Pitch).

I've found that anything with bit depth higher than 2 will result in a lot of flickering when using the sample gifs.

If you've having issues with the wireless sync, replace the code in code.py on each of your devices with the code in espnow_test_display.py and turn them both on at the same time. Plug any error codes you see into Claude and it'll tell you how to resolve them.

All code and gifs were created via Claude.
